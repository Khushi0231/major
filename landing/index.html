Install

1. Download DRAVIS

Click the download button for your platform. You get a native installer — .exe for Windows, .dmg for Mac, .AppImage for Linux. No Docker, no terminal.

2. Install like any app

Run the installer. DRAVIS installs to your Applications folder / Program Files just like any other desktop app. Ollama must be installed — get it free here.

3. Open & go

Launch DRAVIS. On first run it downloads the AI model (~2 GB, one time only). After that — fully offline, no internet needed.

Or install via terminal (Linux / Mac)
curl -fsSL https://raw.githubusercontent.com/Khushi0231/major/main/installers/install-dravis-linux.sh | bash
