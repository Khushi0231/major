How It Works

One installer does everything

No technical setup required. The installer handles Docker, the AI model, and the app.

1

Download the Installer

One file: .command for Mac, .ps1 for Windows, .sh for Linux. No admin password needed on first run for Mac.

2

Run it Once

Double-click the file. It installs Docker (if needed), clones DRAVIS, and downloads the Mistral 7B AI model. Takes ~10 min on first run.

3

DRAVIS Opens

Your browser opens automatically to http://localhost. The green dot confirms your private AI is live.

4

Always-on Offline

Next time: run docker compose up -d or double-click again. The model is cached — starts instantly.
