Your AI study assistant.
Entirely offline.

DRAVIS runs Mistral 7B locally via Ollama. No cloud, no API keys, no limits. Upload your docs, chat, generate quizzes — all on your machine.

Download for Mac Windows Linux
Requires Docker · ~6 GB disk · 16 GB RAM recommended · NVIDIA GPU optional
Install

Download the installer

One file per platform. Double-click on Mac, right-click → Run with PowerShell on Windows.

It handles everything

Installs Docker if needed, clones DRAVIS, downloads Mistral 7B (~4.5 GB, one time only).

Open localhost

Your browser opens to http://localhost. The green indicator means your local AI is live.

Or install via terminal
curl -fsSL https://raw.githubusercontent.com/Khushi0231/major/main/installers/install-dravis-linux.sh | bash
Features
🧠

Mistral 7B Instruct

Full 7 billion parameter model. Real reasoning, not a mini version.

📚

Study from your docs

Upload PDF, DOCX, PPTX. AI answers from your own notes and material.

📝

Quiz generation

MCQ, true/false, short answer. From any topic or your uploaded docs.

🗣️

Voice input

Speak your questions. Whisper transcribes for hands-free study.

🌐

Multilingual

English, Hindi, Hinglish. Auto-detects and responds in your language.

🔒

PIN protected

4-digit lock. Everything stays local — zero telemetry, zero cloud.
