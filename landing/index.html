Setup Guide

Up and running in 3 steps

Everything — AI model, vector store, backend, frontend — starts with one command.

1

Clone the Repository

Download the DRAVIS source code from GitHub. No model files included — they download automatically.

git clone https://github.com/your-org/dravis.git
2

Start with Docker Compose

This pulls the Mistral 7B model (~4.5 GB, one-time), builds the app, and starts all services. Subsequent starts are instant.

cd dravis && docker-compose up --build -d

⏳ First run ~5 min (model download). After that, instant start.

3

Open DRAVIS

Navigate to localhost in your browser. The green indicator confirms your local Mistral 7B is live and responding.

http://localhost

✅ Green indicator = AI ready. Start chatting offline.

Choose Your Platform

Docker Compose handles everything. Pick your OS below.

# Linux / GitHub Codespaces
git clone https://github.com/your-org/dravis.git
cd dravis
docker-compose up --build -d
open http://localhost
# macOS (install Docker Desktop first)
brew install --cask docker
git clone https://github.com/your-org/dravis.git
cd dravis
docker-compose up --build -d
# Windows (Docker Desktop + WSL2 required)
# 1. Install Docker Desktop from https://docker.com
git clone https://github.com/your-org/dravis.git
cd dravis
START.bat ← double click or run in terminal
# NVIDIA GPU — install NVIDIA Container Toolkit first
# https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/install-guide.html
git clone https://github.com/your-org/dravis.git
cd dravis
