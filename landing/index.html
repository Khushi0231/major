Your AI study assistant.
Entirely offline.

DRAVIS runs Mistral 7B locally via Ollama. No cloud, no API keys, no limits. Upload docs, chat, generate quizzes ΓÇö all on your machine.

Requires Docker ┬╖ ~6 GB disk ┬╖ 16 GB RAM recommended
Install

Download the installer

One file per platform. On Mac/Linux open Terminal and run it. On Windows, save the file then right-click it → "Run with PowerShell".

It handles everything

Installs Docker if needed, downloads pre-built DRAVIS images, pulls Mistral 7B (~4.5 GB, one time only).

Open localhost

Your browser opens to http://localhost. Start chatting with your private AI. Fully offline from now on.

Or install via terminal (Linux / Mac)
curl -fsSL https://raw.githubusercontent.com/Khushi0231/major/main/installers/install-dravis-linux.sh | bash
